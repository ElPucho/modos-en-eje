# Modos en eje

Aplicación web para practicar la improvisación modal en guitarra. Incluye metrónomo, cambios de modo imprevisibles anunciados por voz, diapasón, batería de jazz y fórmulas pentatónicas editables.

La sesión queda siempre arriba. Las demás secciones se pueden ordenar con las flechas y el orden se guarda en este dispositivo. En iPhone, el diapasón muestra cinco trastes cada vez para facilitar la lectura.

Los ajustes y las fórmulas se guardan en el navegador. La aplicación puede añadirse a la pantalla de inicio del iPhone desde Safari.
